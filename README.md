# ApprenticeBridge — Next.js Frontend

This version preserves the existing ApprenticeBridge demo flows and adds the requested frontend upgrades:

- Modern landing/home page with hero, feature flash cards, workflow section and CTA.
- Responsive role-based sidebar with mobile drawer navigation.
- Responsive candidate, employer and admin portals.
- Candidate performance analytics using the existing seed/application/skill data.
- ATS Resume Analyzer using resume text plus a target job description.
- Next.js + React + JavaScript + Tailwind CSS frontend.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

The current project is a frontend demo with the original in-memory seed data and existing demo role switching preserved.
